# 数据说明 | Dataset Notes

## 

本课程所使用的 **Stata 数据集由任课老师提供**。考虑到版权和再分发权限，本仓库**不提供原始 `.dta` 数据文件**。

如需复现作业，请通过任课老师或其他合法授权渠道获取相应数据，将其放入本地项目的 `data/` 文件夹，并保持文件名与 Stata 脚本一致（包括大小写）。

脚本引用的数据集文件名：

`401K.DTA`, `401ksubs.dta`, `CEOSAL2.DTA`, `countymurders.dta`, `discrim.dta`, `GPA1.DTA`, `hprice1.dta`, `HTV.DTA`, `MEAP93.DTA`, `SLEEP75.DTA`, `VOTE1.DTA`, `WAGE2.DTA`。

## 

The **Stata datasets for this course were provided by the course instructor**. The original `.dta` files are **not distributed here** because of copyright and redistribution considerations.

To reproduce the exercises, obtain the required files from the instructor or another authorized source, place them in a local `data/` directory, and preserve their exact filenames (including capitalization). Run the Stata scripts from the repository root.
